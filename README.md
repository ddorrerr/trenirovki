# Тренировки

Личное приложение для тренировок: программы от тренера, комментарии,
фактические веса и прогресс. Русский интерфейс, mobile-first, без логина.

- **Стек**: Vite + React + TypeScript + Tailwind v4.
- **Данные, два режима** (общий интерфейс `StorageAdapter`, см. `src/config.ts`):
  - *локальный* (по умолчанию в разработке): `src/data/seed.json` + правки
    в localStorage (`src/storage/local.ts`);
  - *GitHub* (продакшен, включается переменной сборки
    `VITE_DATA_REPO="owner/repo"`): данные одним файлом `data.json`
    в приватном репозитории, доступ по ключу (fine-grained token на один
    репозиторий), очередь несохранённых правок в localStorage, конфликт SHA
    решается перечиткой и слиянием (`src/storage/github.ts`).
- **Деплой**: GitHub Pages, автосборка на каждый push в main
  (`.github/workflows/deploy.yml`); адрес data-репозитория задаётся
  переменной Actions `DATA_REPO`. База путей — `/trenirovki/`.
- **Импорт из таблицы**: `tools/import/import.py` (см. `tools/import/IMPORT_REPORT.md`).
  ⚠ Каталог `tools/import` и настоящий `seed.json` содержат личные данные —
  в публичный репозиторий они не публикуются (см. план публикации ниже).

## Публикация (без утечки данных)

История этого рабочего репозитория содержит личные данные (seed, отчёты
импорта). В публичный репозиторий приложения уходит **очищенная копия**:
свежий `git init`, файлы без `tools/import/*` и с пустым
`src/data/seed.json` (`{"exercises": [], "workouts": []}`). Реальные данные
живут только в приватном data-репозитории.

## Команды

```bash
npm install
npm run dev        # локальная разработка (доступно и с телефона в той же сети)
npm run build      # типы + прод-сборка
```
